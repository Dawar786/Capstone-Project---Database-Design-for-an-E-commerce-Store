Dawarshop – Merchandise Store for Coders 🛍️💻
Dawarshop is a fictional merchandise store tailored for developers, offering hoodies, mugs, stickers, notebooks, and accessories.
This project is designed to showcase database design, table relationships, foreign keys, and business-style SQL analysis with realistic demo data.

📌 Project Overview
Dawarshop simulates a real-world e-commerce database environment, enabling you to:

Understand relational database modeling.
Implement foreign key constraints for data integrity.
Work with realistic sample data for meaningful queries.
Perform business-oriented SQL analysis to extract insights.
🗂️ Features
Product Catalog: Hoodies, mugs, stickers, notebooks, and accessories.
Customer Management: Store customer details and purchase history.
Order Tracking: Manage orders, items, and payment details.
Inventory Control: Track stock levels and product availability.
Business Insights: Analyze sales trends, top products, and customer behavior.
📊 Database Design
The database includes:

Products Table – Stores product details.
Customers Table – Holds customer information.
Orders Table – Tracks order metadata.
Order_Items Table – Links orders to products.
Categories Table – Groups products into categories.
Payments Table – Records payment transactions.
Key Concepts Demonstrated:

One-to-Many and Many-to-Many relationships.
Foreign keys for referential integrity.
JOIN operations for multi-table queries.
